## What's new

**Windows**

- **First Windows build.** Thoth Reader now has an installer for Windows 10/11 (x64), built from the same source as the macOS app. API keys and sign-in tokens are stored in files encrypted for your Windows user account.
- The Windows build is new. It is built and exercised by an automated run on GitHub's Windows machines (books open, translate, and render in every view), but it has not been used by a person on a Windows PC yet. Export, file dialogs, full screen, ChatGPT sign-in, Codex and a real model server have not been tried on Windows. Reports are welcome.

**macOS**

- No functional changes since 1.1.0.

**Builds**

- Both installers are now built on GitHub Actions from the version tag.

## Install

**macOS** — requires macOS 13 or later on Apple Silicon. Open the `.dmg` and drag **Thoth Reader** to Applications.

This build is not signed with an Apple Developer ID or notarized. After copying it to Applications, run once:

```bash
xattr -dr com.apple.quarantine "/Applications/Thoth Reader.app"
```

**Windows** — requires Windows 10 or 11 (x64). Run `Thoth.Reader_1.2.0_x64-setup.exe`; it installs for the current user without administrator rights. Windows 10 may need the [WebView2 runtime](https://developer.microsoft.com/microsoft-edge/webview2/), which the installer downloads if it is missing.

The installer is not code-signed, so Windows SmartScreen shows "Windows protected your PC". Choose *More info → Run anyway*.

SHA-256 checksums are attached next to each file (`.sha256`).
