## What's new

**PDF reflow**

Paragraphs in the reflowed view (and therefore in the translation) were often cut in the middle of a sentence. On a sample of 40 books the number of such cuts fell by about 70%.

- A line set mostly in another face — inline code, a bold lead-in, smaller type — no longer ends the paragraph when the sentence reads on.
- Prose is no longer cut into single lines on pages that also carry tightly set code listings.
- Paragraphs with a hanging indent and no list marker are joined.
- A line split by a wide gap (a label and its title, widely spaced justified words) is read as one line; table-like rows stay apart.
- Margin notes no longer interrupt the paragraph beside them; they follow it.
- One wider line gap inside a sentence (the first line of a column, the line after an inline figure) is not a paragraph break.

## Notes

- PDFs already in your library are re-extracted the first time you open them. Paragraphs whose text did not change keep their translation; paragraphs that were joined are translated again.
- The rule "the sentence reads on" relies on lower-case letters, so it helps with English and similar languages only.
- Still not handled: books that mix two line spacings, formula-heavy pages, magazine-style multi-column layouts.
- The Windows build has still not been used by a person on a Windows PC.

## Install

**macOS** — requires macOS 13 or later on Apple Silicon. Open the `.dmg` and drag **Thoth Reader** to Applications.

This build is not signed with an Apple Developer ID or notarized. After copying it to Applications, run once:

```bash
xattr -dr com.apple.quarantine "/Applications/Thoth Reader.app"
```

**Windows** — requires Windows 10 or 11 (x64). Run `Thoth.Reader_1.2.1_x64-setup.exe`; it installs for the current user without administrator rights.

The installer is not code-signed, so Windows SmartScreen shows "Windows protected your PC". Choose *More info → Run anyway*.

SHA-256 checksums are attached next to each file (`.sha256`).
