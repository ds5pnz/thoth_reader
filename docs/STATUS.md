## 알려진 제한

- PDF: 구조 트리 미사용, RTL·세로쓰기는 표시만, 그림은 이미지로 놓인 것만 블록으로 만든다(벡터 도형으로 그린 도표는 제외), 하이픈 처리는 휴리스틱. 첫 추출 배치(1쪽)는 running header 판정이 적용되지 않는다.
- EPUB 원문 모드는 epub.js `blobUrl` 방식(샌드박스 iframe, 스크립트 불가). `freezePrototype`는 xmldom 충돌로 비활성(ADR 0004).
- 추론(thinking) 모델은 연결 검사에서 `reasoning_effort: "none"`이 검증된 경우에만 비활성화한다. 검증되지 않으면 그대로 느리게 동작한다.
- 번역 품질 2인 검수(§10.4), @wdio/tauri-service 기반 E2E는 수행하지 않았다. 대신 debug 전용 자기 테스트 하네스를 사용한다.

## 서재 화면 (표지 · 메타데이터 · 정렬)

- EPUB: 가져올 때 안전 패키지를 만들면서 `dc:creator` / `dc:publisher` / `dc:date`와 표지(EPUB2 `meta name="cover"`, EPUB3 `cover-image`, 없으면 첫 본문 이미지)를 수집한다. 이전에 가져온 EPUB은 앱 시작 시 한 번 백필한다.
- PDF: 서재에서 1쪽을 한 번 렌더링해 420px JPEG 표지로 저장하고 Info의 Title/Author를 읽는다(리더 세션을 열지 않으며, 2분짜리 단일 파일 읽기 토큰 사용). 암호화·손상 PDF는 일반 표지.
- 표지는 `covers/<documentId>.<ext>`에 저장되고 `thoth-doc://localhost/cover/<documentId>`로만 제공된다(매직 바이트 검사, 20 MiB 상한, 문서 삭제 시 함께 삭제).
- 정렬: 최근 읽은 순(읽지 않은 책은 최근 가져온 순으로 뒤에) / 제목 순(가나다 → ABC, 숫자 자연 정렬). 선택은 유지된다.
- 자가 검증(`THOTH_SELFTEST_SCENARIO=library`, EPUB 8 + PDF 8): 표지 이미지 16/16, 깨진 이미지 0, 저자 표시 15/16, 표지 비율 2:3 16/16, 제목 정렬·최근 정렬 확인.

## 코드 리뷰 (전 영역) 결과

영역별 리뷰 6건(Rust IPC·문서, 번역·프로바이더, 저장소·도메인, EPUB 새니타이저, 리더 UI, PDF 파이프라인)에서 확인된 문제를 수정했다.

수정됨
- 문서: EPUB 패키지 게시 순서(섹션·메타데이터 → 디렉터리 rename), 삭제·가져오기와 패키지 빌드의 경합, 스테이징/표지 임시 파일 정리, 이미 준비된 책은 빌드 락 없이 열림, Range 응답 16 MiB 상한, 실패 표시의 extraction 범위 검사, PDF 섹션 생성 단일 트랜잭션.
- 저장소: 읽기 전용 모드를 SQLite `query_only`로 강제, 이전 생성 번역 적용이 되돌려지던 문제(캐시 재지정), 실패한 삭제가 다음 실행에 재실행되던 문제, 반복 실패 마이그레이션의 백업 누적, FK 자식 인덱스(0004), 로그 마스킹 보강과 문자 경계 절단.
- 번역: 실패한 블록을 스크롤만으로 재전송하지 않음(5분, 명시적 재시도는 즉시), 다른 세션에 합쳐진 대기 작업이 영구 대기하던 문제, 오류 종료 시 작업 행이 활성 상태로 남던 문제, 취소 이벤트 누락, 컨텍스트가 모델 창을 넘으면 컨텍스트를 생략, 응답 앞의 `<think>` 블록 제거.
- EPUB 새니타이저: HTML 파서 노드·깊이·작업량 상한, CSS 주석 위조 우회, 누락 참조 수집의 2차 시간, 인라인 `<style>` 파일 폭증, zip64 엔트리 수 사전 검사, SVG `<use>` 연쇄, 이스케이프된 `url(`.
- 리더: 스크롤 앵커 캡처가 가시성 보고에 덮이던 문제, EPUB 원문 보기의 오래된 섹션 목록, 가상화로 사라지던 편집 초안, 모드 전환 직전 스크롤의 앵커 반영, 모달이 열린 동안의 단축키와 포커스, 한글 입력 상태의 단축키, generation 역행, 북마크 목록 갱신.
- PDF: 화면을 벗어난 페이지 캔버스 해제, 손상된 한 페이지가 전체 추출을 멈추던 문제, pdf.js 6 텍스트 레이어 CSS, 오래된 세션 스냅샷 덮어쓰기.

알려진 한계(미수정)
- 재시도 대기(backoff) 중 실행 슬롯을 계속 점유한다. 프로바이더 probe 결과가 모델별이 아니라 프로바이더 단위로 저장되어, 다른 모델을 probe하면 기존 프로필의 요청 옵션이 달라질 수 있다.
- PDF: Range 없는 전체 GET은 파일 전체를 메모리에 읽는다. 반복 머리글 감지가 배치 구성에 좌우된다. RTL 줄의 단어 순서, 번역 오버레이 확장 영역의 중복 가능성.
- Rust/TypeScript canonical JSON은 2^53 초과 정수에서 표기가 다르다(현재 해당 값 없음).
- 새니타이저 출력이 일부 입력에서 달라졌지만(`<style>` 여러 개 병합 등) 기존 번역을 보존하려고 규칙 버전은 올리지 않았다. 이미 가져온 EPUB은 이전 규칙으로 만든 패키지를 계속 쓴다.

검증: Rust 단위 테스트 245, 프런트 144, 실기 자가 검증 — 모드 전환 20회(EPUB 2 + PDF 2) 위치 변화 0, 악성 EPUB 32개 6회 반복(거부 17 · 무해화 15 · 위반 0), 서재(표지 10/10), mock 프로바이더 번역(오버레이 넘침 0, 실패 0).

## PDF 목차 · 페이지를 넘는 문장 · 색상 강조

- 목차: PDF에 아웃라인(책갈피)이 있으면 그것을 사이드바 목차로 쓴다(계층·쪽 번호 표시, 대상 쪽을 찾지 못한 항목은 앞 항목의 쪽으로). 아웃라인이 없으면 쪽 목록.
- 페이지를 넘는 문장: 쪽의 마지막 본문 블록이 문장 중간에서 끝나고(`continues_on_next_page`) 다음 쪽이 본문으로 시작하면, 두 블록을 `<pb/>` 표식으로 이은 한 덩어리로 번역하고 각 블록은 표식 기준 자기 쪽 절반만 저장한다. 표식이 사라지거나 반복되면 원문 길이 비율로 단어 경계에서 나눈다. 블록·캐시·이력 구조는 그대로이며, 절반마다 요청이 한 번씩 나간다.
- 색상 강조: 텍스트 그리기 연산자의 채움색을 텍스트 항목에 맞춰(일치율 90% 미만인 쪽은 색을 쓰지 않음) 블록의 주된 색과 뚜렷이 다른 구간을 `color` 노드로 추출한다. 번역에는 `<c>…</c>` 쌍으로 전달되어 `c:#rrggbb` 범위로 저장된다. 블록당 강조색 하나.
- PDF 추출기 v4: 기존 PDF는 다음에 열 때 다시 추출·번역된다. EPUB의 색상(CSS)은 대상이 아니다.

## EPUB 보강 · 뷰어 다듬기 · 아이콘

- 번역된 EPUB 내보내기: 섹션마다 XHTML 한 개, 목차는 원래 장 제목, 책의 (새니타이즈된) 래스터 그림 포함. 내보낸 파일을 앱의 엄격한 EPUB 가져오기로 다시 검증(제한 0, 실패 섹션 0).
- EPUB 원문 모드: 형광펜·메모·선택 번역·복사. iframe이 스크립트 없는 샌드박스라 WebKit이 그 안의 이벤트 리스너를 실행하지 않으므로, 선택은 바깥에서 300ms마다 확인하고 키보드 포커스는 뷰로 되돌린다링크도 같은 이유로 바깥에서 처리한다: 렌더된 장의 모든 링크를 문서 안 조각 이동(`#thoth-l-N`)으로 바꾸고 실제 대상은 `data-thoth-href`에 두며, 프레임 주소의 조각이 바뀌는 것을 150ms마다 확인해 외부 링크는 Rust의 open_external로, 책 안 링크는 해당 장·위치로 이동시킨다(실제 EPUB에서 책 안 링크 이동 확인; 외부 링크는 단위 테스트만).
- EPUB 쪽 넘김: 스크롤 / 쪽 넘김, 1단 / 2단. ←/→, Page Up/Down, 양옆 버튼. 넘김 방식을 바꿔도 읽던 쪽으로 돌아온다. 리플로우(병렬·교차) 화면에는 적용되지 않는다.
- PDF 도구 막대: 포인터가 아래쪽에 있을 때만 표시. 폭 맞춤 / 쪽 맞춤, Space·⇧Space·←/→·Page Up/Down으로 쪽 이동. 확대 시 가로 스크롤이 되지 않던 문제(읽기 영역이 내용만큼 넓어지던 것) 수정.
- 상단 바: 서재·내보내기 아이콘, 전체 화면(⇧⌘F, Esc로 종료). 전체 화면에서는 상단 바와 사이드바를 숨기고 포인터가 위쪽 가장자리에 닿으면 상단 바가 나온다.
- 앱 아이콘: 왼쪽 쪽에 "Th", 오른쪽 쪽에 "th", 가운데 고리 "o" (`scripts/make-icon.swift`).
- 자가 검증 창이 가려진 상태에서는 CSS 전환·IntersectionObserver가 진행되지 않아, 도구 막대 표시·전체 화면 상단 바·썸네일 렌더링은 이번 실행에서 자동 확인하지 못했다(썸네일은 이전 실행에서 확인).

## ChatGPT 요금제 · Codex 연동 (2026-11-15)

- **ChatGPT 요금제(Sign in with ChatGPT)**: OpenAI의 오픈소스·로컬 앱용 "ChatGPT plan usage" 흐름을 따른다. 첫 로그인은 `client_id=dynamic_agent_client`로 앱을 등록하고 콜백으로 발급된 client id를 저장하며, 이후에는 그 id로 재인증한다. 인증 코드 + PKCE(S256), 시도마다 새 `state`·`nonce`, 루프백 콜백 `http://127.0.0.1:<port>/auth/callback`(기본 1455, 사용 중이면 빈 포트). ID 토큰은 OpenAI JWKS로 RS256 서명·issuer·audience(발급 client id)·만료·nonce를 확인한 뒤에만 저장한다. 요금제 사용은 `chatgpt.tokens.use.direct` 스코프가 부여됐을 때만 켠다.
- 자격 증명(액세스·리프레시·ID 토큰, client id, host id)은 Provider마다 키체인 항목 하나에 JSON으로 둔다. 리프레시 토큰이 회전하므로 갱신은 등록 단위로 직렬화하고, 쓸 수 없게 된 토큰은 지우되 등록 정보는 남겨 같은 client id로 다시 로그인한다. 로그아웃은 revocation endpoint로 세션을 끊고 토큰을 지운다.
- 번역 요청은 `POST /v1/responses`에 `store:false`, `stream:true`로 보낸다. 시스템 메시지는 `instructions`로 옮기고, 요금제 사용에서 거절되는 필드(temperature, 토큰 한도 등)는 보내지 않는다. `response.completed`를 받아야 성공이다. 사용 한도(`subscription_sharing_usage_limit_exceeded`)는 재시도 없이 멈추고 ChatGPT 설정의 Usage를 안내한다. 다른 결제 경로로 바꾸지 않는다.
- **Codex**: 이 Mac의 `codex app-server`를 stdio JSON-RPC로 띄워 문단마다 일회용 스레드(읽기 전용 샌드박스, 승인 없음, 빈 작업 폴더, 번역 지시문으로 교체한 base instructions)에서 한 턴을 돌린다. 도구 사용이 감지되거나 서버가 승인을 요청하면 그 요청을 실패로 끝낸다. 앱은 Codex의 토큰을 읽지 않는다.
- 저장: `providers.kind` 열의 CHECK 제약을 건드리지 않도록 두 종류 모두 `openai_compatible`로 저장하고 `capabilities.variant`(`chatgpt`·`codex`)로 구분한다.
- 검증: 가짜 인증·API 서버를 상대로 한 시험(서명·클레임 검증, 등록/재인증, 다른 계정·nonce 불일치 거부, 토큰 갱신·회전, 사용 한도·로그인 필요 오류, 모델 목록) 통과. Codex는 실제 앱에서 공개 도서 EPUB 병렬 보기 첫 화면이 약 19초에 번역됨(gpt-6.1-sol, effort low). 실제 OpenAI 인증 서버에는 authorize 요청이 로그인 화면으로 넘어가는 것까지만 확인했고, **ChatGPT 계정으로 실제 로그인해 번역하는 것은 확인하지 못했다.**

## 번역 칸의 그림 · 번역 전용 보기 · 원문 다크 모드 · Provider 전환과 삭제 (2026-11-15)

- **그림**: 병렬·번역 전용 보기에서 그림이 든 문단은 번역 쪽에도 같은 그림을 보여 준다(교차 보기는 원문 바로 아래라 생략). 캡션이 같은 블록에 든 그림(Figure)은 추출 때 "보존"으로 저장돼 있지만, 글자가 있으면 읽는 시점에 번역 대상으로 본다(`Block::base_policy`). 재추출 없이 기존 책에도 적용된다.
- **번역 전용 보기**: 읽기 모드에 `translation`이 추가됐다. 리플로우에서는 번역문만 한 단으로 보여 주고 문단을 누르면 그 아래에 원문이 펼쳐진다(다시 누르면 닫힘, 번역할 것이 없는 문단은 원문 그대로). PDF 쪽 보기에서는 번역된 쪽만 보여 주고(원본 쪽은 번역 쪽을 그리는 데 필요해 보이지 않게 렌더링) 문단을 누르면 팝오버에 원문이 함께 나온다.
- **EPUB 원문 보기 다크 모드**: 책 문서의 `<html>`에 클래스를 달고 글자·배경·테두리 색만 덮어쓰는 스타일을 넣는다. 책의 스타일시트는 그대로 두고, 그림에는 밝은 바탕을 남긴다(투명 배경 선화 대비).
- **Provider 전환**: 목록의 "사용" 버튼이 그 Provider에서 마지막으로 만든 프로필로 한 번에 전환한다(`provider_use`). 모델을 고른 적이 없으면 안내만 한다. 설정을 열면 번역 중인 Provider가 선택돼 있고, 로컬·계정형 Provider는 열 때 모델 목록을 자동으로 불러온다.
- **Provider 삭제**: `provider_remove`는 행을 지우지 않고(번역 이력이 참조) `capabilities.removed`로 숨기며, 비활성화하고 키체인의 키·로그인 정보를 지운다. 사용 중이던 Provider면 활성 프로필을 비운다.
- 실제 앱 확인: 그림 있는 EPUB에서 번역 쪽 그림 표시·캡션 번역, 번역 전용 보기에서 원문 숨김·클릭 시 표시·다시 닫힘, 다크 원문(본문 배경 rgb(30,33,37)·글자 rgb(230,227,220), 밝은 테마로 되돌리면 해제), PDF 번역 전용(번역 쪽 한 장, 팝오버 원문), Provider 전환·모델 선택·삭제 흐름.
